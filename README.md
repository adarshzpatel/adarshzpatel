# Adarsh Patel

Frontend engineer in India. I build editors, charts and the tools I use every day.

Right now I work at [Morphic](https://morphic.com), a browser workspace for making AI video from brief to finished film. I work across the studio app (SvelteKit), the backend and the shared libraries.

## Side projects

- [candleframe](https://github.com/adarshzpatel/candleframe). A WebGL2 candlestick chart engine in TypeScript with no runtime dependencies. It streams live Binance and Hyperliquid data, or a trade simulator that works offline. [Docs and demos](https://adarshpatel.github.io/candleframe/)
- [paca](https://github.com/adarshzpatel/paca). A native macOS app in Swift for [herdr](https://herdr.dev). It shows your coding agents in a Slack-style window and a menu bar item.

## Before Morphic

I spent a few years in web3 and shipped hackathon projects like [polylinks](https://github.com/adarshzpatel/polylinks) (Moralis hackathon 2022) and [superstream](https://github.com/adarshzpatel/superstream-ethernals).
